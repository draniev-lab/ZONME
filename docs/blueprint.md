# **App Name**: ZoeHouse

## Core Features:

- User Authentication and Authorization: Secure user registration and login system with email, phone, Google, and Facebook options. Includes phone verification and KYC (CNI, passport, selfie) for enhanced security.
- Property Listing Management: Allow users to add, modify, and remove property listings with details such as title, description, type, status, price, address, geolocation, surface area, features, documents, photos, videos, and tags.
- Advanced Property Search: Enable users to search for properties based on various filters such as location, budget, property type, number of bedrooms, status, availability, and distance, with advanced search capabilities like full-text search and map-based search.
- Booking and Visit Scheduling: Facilitate physical visit requests with a visit calendar, instant booking options, and confirmation notifications via push and email.
- Integrated Messaging System: Real-time chat between clients, owners, and agents, supporting file sharing and instant notifications to facilitate communication and property inquiries.
- Intelligent Property Recommendations: Employ a tool that analyzes user preferences and historical data to automatically recommend properties based on budget, preferred location, property type, and browsing history, enhancing property discovery.
- Admin Back-Office: Provide a comprehensive admin dashboard for managing users, properties, payments, commissions, documents, and general settings such as zones, fees, and subscriptions.

## Style Guidelines:

- Primary color: A vibrant, earthy orange (#FF7733) to evoke feelings of home and excitement.
- Background color: Light tan (#FAF0E6) provides a clean, neutral backdrop, ensuring readability and highlighting the property listings.
- Accent color: Sky blue (#3399FF) to signify trust and serenity.
- Headline font: 'Playfair', a modern serif with an elegant, high-end feel
- Body font: 'PT Sans', a humanist sans-serif for comfortable readability in property descriptions and user interfaces
- Simple, clean icons for property features, search filters, and user actions, enhancing usability and visual appeal.
- Subtle transitions and animations to indicate loading states and user interactions, providing a polished and responsive user experience.
